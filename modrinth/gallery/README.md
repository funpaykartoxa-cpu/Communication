# Галерея Modrinth

Все изображения — **1920×1080**, оформлены в тёмно-синей палитре мода (`#859CFF`). Это дизайн-схемы интерфейса, а не игровые скриншоты; на каждом изображении есть соответствующая пометка.

| Файл | Название на Modrinth | Описание |
|---|---|---|
| `01-hero.png` | Communication — пати, метки и оверлей ESC | Обложка проекта: назначение мода и ключевые функции. |
| `02-party.png` | Пати по коду | Команды `.party`, код из 6 символов и защищённый канал. |
| `03-overlay.png` | Оверлей ESC | Состав пати, сердца, инвентарь, броня и тултипы. |
| `04-marks.png` | Метки в мире | Метка на блоке, звук у получателей и подпись с расстоянием. |
| `05-settings.png` | Настройки на Right Shift | Компактное меню: пати, клавиши меток и громкость. |
| `06-install.png` | Установка | Fabric Loader, Fabric API и jar в папку `mods`. |

## Порядок загрузки

1. `01-hero.png` — обложка.
2. `02-party.png`
3. `03-overlay.png`
4. `04-marks.png`
5. `05-settings.png`
6. `06-install.png`

## Перегенерация

```bash
python modrinth/tools/make_gallery.py
```

Скрипт использует `modrinth/icon.png` и системные шрифты Windows (Segoe UI, Consolas, Bahnschrift).
