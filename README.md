# Communication

**Communication** — лёгкий клиентский Fabric-мод для Minecraft **1.21.4**, который добавляет только функции связи: пати, метки игроков и информационный оверлей на экране паузы. Дополнительный клиент для этого не нужен.

Мод работает на стороне клиента и использует общий backend для обмена зашифрованными пакетами пати. Установка на сервер не требуется.

---

## Что умеет мод

### Пати

- Создание пати одной командой `.party create`.
- Вход по коду `.party join <код>`.
- Выход `.party leave` и просмотр состава `.party info`.
- Код пати состоит из **6 символов** и генерируется из алфавита без похожих символов: `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.
- При входе принимается код из **4–12 букв и цифр**, регистр не важен, дефисы и пробелы игнорируются.
- Участники автоматически удаляются из списка, если не присылали состояние **7 секунд**.
- При входе нового участника остальные клиенты отвечают своим состоянием, чтобы новый игрок сразу увидел состав.

### Синхронизация состояния

Каждую секунду участники отправляют:

- текущее и максимальное здоровье;
- поглощение (absorption);
- измерение;
- адрес сервера;
- номер анархии;
- время отправки.

Раз в **5 секунд** или при изменении инвентаря отправляется полный снимок инвентаря:

- 36 слотов основного инвентаря;
- 4 слота брони;
- слот оффхенда;
- количество предметов;
- полные NBT-данные и компоненты предмета.

Благодаря NBT/компонентам на другом клиенте отображаются кастомные названия, лор, зачарования, модели ресурспака и другие данные предмета, а не только стандартная иконка.

### Оверлей ESC

При открытии меню паузы **ESC** поверх него показывается карточка пати.

В оверлее есть:

- название пати и код;
- количество участников;
- карточки **других** участников (свой персонаж не дублируется);
- скин-голова;
- имя;
- текущее и максимальное HP;
- ванильные сердца, включая сердца поглощения;
- красная строка `anarchy <n>`, если удалось определить анархию;
- измерение, если анархия не определена;
- инвентарь: 27 основных слотов + 9 слотов хотбара;
- вертикальная колонка брони;
- слот оффхенда;
- тултипы при наведении на предмет;
- превью содержимого шалкера при наведении;
- подсказка по копированию кода.

Код пати копируется в буфер обмена **левым кликом** по нему. После копирования в чат приходит подтверждение.

Если участников больше восьми, показываются первые восемь карточек, а снизу выводится количество скрытых.

### Метки пати

- Метка ставится на блок под прицелом на расстоянии до **128 блоков**.
- Метка видна всем участникам пати **5 секунд**.
- Отправитель видит свою метку сразу.
- У получателей проигрывается звук `party_mark.wav` с громкостью из настроек.
- Метка рисуется как пульсирующее кольцо на верхней грани блока.
- Если метка перекрыта блоками, дополнительно рисуется вертикальный луч высотой **48 блоков**.
- На HUD рядом с прицелом отображается подпись с именем отправителя и расстоянием.
- Подпись располагается на фиксированном радиусе **58 px** от центра экрана.
- Учитываются сервер, измерение и номер анархии: метка с другого сервера или измерения не показывается.

### Метки друзьям

- Отдельная метка, которая отправляется в общий канал `friend`.
- Позиция метки — текущая позиция игрока.
- Метка живёт **5 секунд**.
- Отображается у всех клиентов, использующих этот backend; списка друзей нет, поэтому показываются все полученные метки.
- На HUD выводится компактная плашка с головой игрока, именем и расстоянием.
- Действуют фильтры по измерению, серверу и анархии.

### Настройки

Минимальный GUI открывается клавишей **Right Shift**.

В нём можно:

- включить или выключить Communication (по умолчанию включён);
- создать пати;
- ввести код и войти в пати;
- выйти из пати;
- назначить клавиши метки пати и метки друзьям;
- изменить громкость звука метки пати;
- посмотреть текущий код и количество участников.

Те же две клавиши зарегистрированы в ванильном меню **Настройки → Управление → Клавиши** в категории **Communication**. Назначать их можно в любом из двух мест — изменения сразу синхронизируются и сохраняются в конфиг.

Клавиши меток по умолчанию **не назначены** — их нужно задать вручную.

## Как это работает

### Пакеты пати

Внешний пакет выглядит так:

```json
{
  "id": "party",
  "payload": {
    "d": "<base64>"
  }
}
```

Поле `d` — зашифрованные данные:

1. Генерируется случайный IV длиной 12 байт.
2. Ключ вычисляется как `SHA-256` от префикса протокола и нормализованного кода пати.
3. Данные шифруются **AES-256-GCM** с тегом 128 бит.
4. IV + шифротекст кодируются в Base64.

Внутри зашифрованного JSON находятся сообщения:

- `state` — здоровье и инвентарь;
- `join` — вход в пати;
- `leave` — выход;
- `mark` — метка пати.

Формат пакета и криптографический протокол совместимы с другими клиентами, которые используют тот же backend.

### Backend

- Клиент опрашивает очередь раз в секунду.
- Пакеты пати отправляются с временным идентификатором `party-<uuid>`, чтобы backend не отфильтровал их как «свои».
- Пакеты друзей отправляются от имени текущего ника.
- Для обхода блокировки DNS/edge предусмотрен локальный HTTP CONNECT-туннель к резервным edge-адресам.

### Полный инвентарь

Для каждого непустого слота отправляется:

```json
{
  "s": 36,
  "i": "minecraft:diamond_sword",
  "c": 1,
  "n": "<base64 NBT>"
}
```

- `s` — индекс слота;
- `i` — идентификатор предмета;
- `c` — количество;
- `n` — полный NBT-стек в Base64.

При получении NBT читается с ограничением размера **2 МБ** и восстанавливается через `ItemStack.fromNbt`. Если полный NBT недоступен, используется резервное создание предмета по идентификатору.

### Определение анархии

Номер анархии берётся из заголовка tab-листа. Для доступа к заголовку используется mixin-аксессор `PlayerListHudAccessor`. Если заголовок недоступен или номер не найден, возвращается `-1`.

### Проекция координат

Для HUD-подписей используется mixin-инвокер `GameRendererInvoker`, который получает текущий FOV. Позиция метки переводится из мировых координат в экранные с учётом камеры и угла обзора.

## Установка

### Требования

| Компонент | Версия |
|---|---|
| Minecraft | 1.21.4 |
| Fabric Loader | 0.18.4+ |
| Fabric API | 0.119.4+1.21.4 |
| Java | 21 |

### Шаги

1. Установи Fabric Loader для Minecraft 1.21.4.
2. Помести `fabric-api` в папку `mods`.
3. Помести `communication-1.1.0.jar` в ту же папку `mods`.
4. Запусти игру через профиль **Fabric 1.21.4**.

Если игра уже запущена, после копирования jar её нужно перезапустить.

Готовые файлы находятся в разделе **Releases**:

- `communication-1.1.0.jar` — мод;
- `communication-1.1.0-sources.jar` — исходники в виде jar.

SHA-256 для `communication-1.1.0.jar`:

```text
482A4198D1A0505DBBC9CEB8AD4BCA4457A42EA29BFCF03E4224A4890CBD62AD
```

## Быстрый старт

1. Запусти игру с установленным модом.
2. Убедись, что в чате нет ошибок, а в логе есть строка `Communication initialized`.
3. Нажми **Right Shift** — откроется меню Communication.
4. Проверь, что переключатель **Communication** включён.
5. Создай пати: `.party create`.
6. Передай код другу, он вводит `.party join <код>`.
7. Открой **ESC** — появится оверлей с участниками.
8. Назначь клавиши меток в настройках мода или в «Управлении» Minecraft, если они нужны.

## Команды

```text
.party
.party create
.party join <код>
.party leave
.party info
```

Команды обрабатываются на клиенте и **не отправляются на сервер**. Если мод выключен, `.party` всё равно перехватывается и выводит сообщение о том, что функция недоступна.

## Конфигурация

Файл создаётся автоматически:

```text
config/communication.json
```

Пример:

```json
{
  "enabled": true,
  "partyMarkBind": -1,
  "friendMarkBind": -1,
  "partyMarkVolume": 0.8
}
```

Параметры:

- `enabled` — включает и выключает все функции мода;
- `partyMarkBind` — GLFW-код клавиши метки пати, `-1` — не назначена;
- `friendMarkBind` — GLFW-код клавиши метки друзьям, `-1` — не назначена;
- `partyMarkVolume` — громкость звука метки от `0.0` до `1.0`.

Изменения из GUI сохраняются сразу.

## Клавиши

| Действие | Клавиша |
|---|---|
| Открыть/закрыть настройки Communication | Right Shift |
| Закрыть настройки | ESC |
| Метка пати | назначается в GUI или в «Управлении» |
| Метка друзьям | назначается в GUI или в «Управлении» |

Обе метки находятся в категории **Communication** меню «Управление → Клавиши». Назначение в меню мода и в ванильном меню синхронизировано.

Ограничения:

- назначать можно только клавиши клавиатуры;
- Right Shift зарезервирован под открытие меню: если назначить его меткой, привязка сбросится с предупреждением в чате;
- если клавиша уже занята другим модом, конфликт нужно решать настройками другого мода.

## Совместимость

- Мод клиентский, работает на любом сервере.
- Протокол пати совместим с другими клиентами, использующими тот же backend.
- Формат инвентаря (`s`, `i`, `c`, `n`) совместим с другими клиентами.
- Метки друзьям используют тот же пакет `friend` и те же поля.
- В мод намеренно **не входят** посторонние функции: ESP, синхронизация таймеров сундуков и другие модули, не относящиеся к связи.

---

## Приватность и ограничения

- Трафик пати шифруется ключом, производным от кода пати. Код является общим секретом: любой, кто его знает, может войти в пати.
- Отдельной авторизации участников нет.
- Метки друзьям, в отличие от пати, передаются в открытом виде через общий канал `friend`.
- Backend видит только внешние пакеты; содержимое пати зашифровано.
- Для работы пати в сборке заданы адрес backend и параметры доступа.
- Метка пати живёт 5 секунд и не сохраняется между сессиями.
- В оверлее показываются максимум 8 других участников; остальные отмечаются в футере.
- Клавиши меток по умолчанию не назначены.
- Список друзей отсутствует: показываются все полученные метки друзей.

## Если Right Shift не открывает меню

Проверь по порядку:

1. **Jar действительно лежит в `mods`** того профиля, который запускается.
2. **Запущен Fabric-профиль 1.21.4**, а не ванильный Minecraft.
3. **Fabric API установлен** и его версия подходит для 1.21.4.
4. В `logs/latest.log` есть строка:

   ```text
   Communication initialized (party, friend marks, ESC overlay, settings, controls key binds)
   ```

   Если строки нет — мод не загрузился. Проверь ошибки загрузки модов в начале лога.

5. Файл `config/communication.json` создан. Если его нет, мод, скорее всего, не инициализировался.
6. В игре не открыт чат, инвентарь или другой экран. Меню Communication открывается только тогда, когда нет активного экрана.
7. Right Shift не перехвачен другим модом или программой.
8. Игра была перезапущена после копирования jar.

Если мод загружен, но меню не открывается, проверь, не занята ли клавиша Right Shift другим клиентом, и посмотри лог на ошибки ввода.
