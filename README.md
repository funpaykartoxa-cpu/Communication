# Communication

Лёгкий клиентский Fabric-мод для Minecraft **1.21.4**, который добавляет только функции связи: пати, метки и оверлей на экране паузы. Полноценный клиент Delta для этого не нужен.

## Возможности

- **Пати** — создание, вход по коду, выход и список участников через `.party`.
- **Синхронизация состояния** — HP, максимальное HP, поглощение, измерение, сервер и анархия.
- **Полный инвентарь участников** — 36 слотов, броня и оффхенд. Предметы передаются вместе с NBT и компонентами, поэтому сохраняются кастомные названия, зачарования, лор и модели ресурспака.
- **Оверлей ESC** — карточки других участников, ванильные сердца, `anarchy <n>`, инвентарь, тултипы и превью шалкеров.
- **Копирование кода пати** — ЛКМ по коду в оверлее ESC.
- **Метки пати** — метка на блоке под прицелом (до 128 блоков), звуковой сигнал у получателей.
- **Метки друзьям** — отдельная метка с позицией игрока для всех клиентов, использующих общий backend.
- **Настройки** — минимальный GUI только с параметрами Communication: включение модуля, пати, клавиши меток и громкость.
- **Клиентская часть** — мод не требует установки на сервер.

## Требования

- Minecraft **1.21.4**
- Fabric Loader **0.18.4+**
- Fabric API **0.119.4+1.21.4**
- Java **21**

## Установка

1. Установи Fabric Loader для Minecraft 1.21.4.
2. Положи `fabric-api` и `communication-1.0.0.jar` в папку `mods`.
3. Запусти игру.

Готовые файлы лежат в разделе **Releases**:
- `communication-1.0.0.jar` — мод;
- `communication-1.0.0-sources.jar` — исходники в виде jar.

SHA-256 для `communication-1.0.0.jar`:

```text

```

## Использование

### Команды пати

```text
.party create
.party join <код>
.party leave
.party info
.party
```

Код пати состоит из 6 символов, при входе принимаются коды из 4–12 букв и цифр. Регистр не важен.

### Интерфейс

- **Right Shift** — открыть/закрыть настройки Communication.
- **ESC** — оверлей пати поверх меню паузы.
- Клавиши метки пати и метки друзьям назначаются в настройках. По умолчанию они не назначены.
- Громкость звука метки пати регулируется там же.

### Конфиг

Файл создаётся автоматически:

```text
config/communication.json
```

Параметры: `enabled`, `partyMarkBind`, `friendMarkBind`, `partyMarkVolume`.

## Сборка

Нужен JDK 21. Если Gradle не находит Java 21, укажи путь к JDK через `JAVA_HOME` или `org.gradle.java.home` в `gradle.properties`.

```bash
./gradlew clean build
```

Артефакты появятся в `build/libs/`:

```text
communication-1.0.0.jar
communication-1.0.0-sources.jar
```

## Структура проекта

```text
src/main/java/communication/
  command/      обработка .party
  config/       конфигурация
  friend/       метки друзьям
  mixin/        доступ к FOV и заголовку tab-листа
  network/      HTTP-транспорт общего backend
  party/        пати, шифрование, синхронизация и оверлей
  render/       MSDF-шрифты, шейдеры и скруглённые панели
  ui/           экран настроек
  util/         чат, сервер, проекция, звук
src/main/resources/
  assets/communication/   шрифты, шейдеры, иконка, звук, текстура шалкера
  fabric.mod.json
  communication.mixins.json
```

## Примечания

- Мод использует общий backend и AES-256-GCM-протокол кода пати, поэтому совместим с существующими клиентами Delta.
- Синхронизация таймеров сундуков и WardenESP в этот мод намеренно не входят.
- Проект собран как самостоятельный мод и не содержит остальных модулей Delta.
